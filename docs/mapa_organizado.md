## Notas sobre fragilidad del sitio real
El sitio real (flores.go.cr) tiene bastantes problemas propios de infraestructura:
errores de WordPress, páginas 404, links directos a IPs, errores de Composer/PHP
(falta extensión "exif"), y varias páginas que dan error intermitente. Esto no es
algo que nuestro prototipo deba "arreglar" - simplemente lo documentamos para no
confundirlo con errores nuestros.
